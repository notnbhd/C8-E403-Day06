# Hevy AI Insight Chatbot

Chatbot **diễn giải dữ liệu tập gym** từ app Hevy: trả lời câu hỏi tự nhiên về tiến
độ (có tiến bộ không, đang plateau không, nhóm cơ nào bị bỏ bê) và gợi ý routine để
người dùng xác nhận lưu. **Mọi con số do code tính — AI không bịa**; thao tác ghi dữ
liệu luôn cần người dùng xác nhận.

> Chi tiết sản phẩm: [`spec/spec.md`](spec/spec.md) · Kỹ thuật agent: [`codebase/agent/README.md`](codebase/agent/README.md)
